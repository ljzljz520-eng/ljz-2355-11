# 安装 <VersionBadge />

## 包管理器 {#cdn}

```bash
npm install my-lib@2
```

## 仅 ESM {#esm-only}

2.0 起只发布 ESM 产物。1.x 的 UMD/CDN 用法请切换到旧版查看（锚点 `peer-deps` 在新版已移除）。

<details data-block-id="b-cdn-mirror">
<summary>CDN 镜像配置（点击展开）</summary>

```html
<script type="module" src="https://unpkg.com/my-lib@2/dist/es.js"></script>
```

</details>
