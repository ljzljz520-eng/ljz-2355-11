# 快速开始 <VersionBadge />

```js
import { createSdk } from 'my-lib/beta'

const sdk = createSdk({ renderer: 'vue' })
```

这里的 {{t:sdk}} 定义取自 **3.0 预览版词典**（支持双渲染器），与 2.0 不同。

## AI Assistant（仅预览版，受保护）

从 2.x 切换版本时，AI Assistant 章节在 2.x **没有迁移目标**（缺失目标），
切换器会明确告知而不是跳到标题相近的页面。
